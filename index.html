Slides and 2D animation 슬라이드와 2D 애니메이션

Explain the idea.
Show each step. 개념은 슬라이드로,
과정은 움직임으로.

Crimate brings slide editing and 2D animation together. Place diagrams and equations on a slide, then reveal and move them as you explain each step. Edit on the canvas, in a .crim text file or with AI. Crimate는 슬라이드 편집과 2D 애니메이션을 함께 다루는 도구입니다. 그림과 수식을 배치하고, 설명 순서에 맞춰 나타내거나 움직일 수 있습니다. 캔버스에서 직접 편집하거나 .crim 파일을 수정하고, AI에 수정을 요청할 수도 있습니다.

This backpropagation example shows the forward pass first, then the gradients in reverse order. Arrows and values appear as each step is explained. The slide was made and recorded in Crimate. 역전파(backpropagation) 예제입니다. 먼저 순전파 계산을 보여 주고, 이어서 기울기를 역순으로 계산합니다. 각 단계에 맞춰 화살표와 계산값이 나타납니다. Crimate에서 만든 슬라이드를 편집기에서 재생한 화면입니다.

  • Each slide has its own playback range.슬라이드별로 재생 구간을 설정합니다.
  • Arrows extend along straight or curved paths.직선과 곡선 화살표가 경로를 따라 그려집니다.
  • Jump to the next animation with a click or keyboard shortcut.클릭이나 단축키로 다음 애니메이션의 시작 지점으로 이동합니다.

Features기능

Tools for visual explanations설명에 필요한 도구

Start with the canvas. Open tools as you need them.캔버스에서 작업하고, 필요한 도구만 꺼내 씁니다.

  • Canvas-first editing캔버스 중심 편집

    Build diagrams with shapes, arrows, freehand lines, text and images. Move a shape, and its connected arrows follow.도형, 화살표, 자유롭게 그린 선, 텍스트, 이미지로 그림을 구성합니다. 도형을 옮기면 연결된 화살표도 따라 움직입니다.

  • A timeline for each slide슬라이드별 타임라인

    Set when objects appear, move and rotate. Play the sequence or step through the animations as you explain.오브젝트가 나타나고, 이동하고, 회전하는 시점을 정합니다. 연속으로 재생하거나 설명에 맞춰 애니메이션을 한 단계씩 넘길 수 있습니다.

  • LaTeX equationsLaTeX 수식

    Write equations in LaTeX and display them with MathJax, within a sentence or on their own. Their scale stays consistent across devices.LaTeX로 작성한 수식을 MathJax로 표시합니다. 문장 안에 넣거나 별도로 배치할 수 있으며, 기기가 달라도 크기가 일정하게 유지됩니다.

  • Slides saved as text텍스트로 저장하는 슬라이드

    The .crim format describes slides and animations in plain text. Read and edit the file directly, or use a diff to see what changed..crim은 슬라이드와 애니메이션을 텍스트로 표현하는 파일 형식입니다. 파일을 직접 읽고 수정하거나, diff로 변경 내용을 비교할 수 있습니다.

  • Edit with AIAI와 함께 편집

    Mark an area, leave a note and ask AI to make the change. Use your ChatGPT account in the built-in chat, and undo an edit in one step.고칠 영역에 메모를 남기고 AI에 수정을 요청합니다. 내 ChatGPT 계정을 연결해 사용하며, 적용된 수정은 한 번에 되돌릴 수 있습니다.

  • Export from the canvas캔버스 그대로 내보내기

    Save the current slide as a PNG image or record its animation as a WebM video, directly from the canvas.현재 슬라이드는 PNG 이미지로 저장하고, 애니메이션은 WebM 동영상으로 녹화합니다.

Interactive visual lessons직접 실험하는 시각 강의

Follow the explanation.
Then try the idea.설명을 따라보고,
직접 바꿔 이해합니다.

Pair a visual explanation with buttons and sliders on the same slide. Add Cream, a small pixel-art lecturer, to guide each step with a speech bubble or subtitles.설명 애니메이션을 보다가 같은 슬라이드의 버튼과 슬라이더로 직접 실험합니다. 픽셀 캐릭터 강사 Cream은 말풍선이나 자막으로 각 단계를 설명합니다.

  • Controls inside the lesson설명 안에서 직접 조작

    Turn on Animation control to use native buttons and sliders. Start an explanation, change a value or reset the experiment without rewriting the authored slide.애니메이션 단계 제어를 켜면 강의의 버튼과 슬라이더가 작동합니다. 설명을 재생하고 값을 바꾸거나 처음으로 돌아가도 원래 슬라이드는 유지됩니다.

  • Meaning, phrase by phrase의미 구절을 따라가는 강조

    Color meaningful phrases in sequence, like karaoke lyrics. Pause, rewind or reset, and the caption colors return to the same frame. Captions are included in PNG and WebM output.노래방 가사처럼 의미 구절이 차례로 색칠됩니다. 일시정지·되감기·Reset에도 같은 프레임의 강조로 돌아가며 PNG와 WebM 출력에도 포함됩니다.

  • Declare Cream once강사는 한 번만 선언

    Cream is built into the playback engine. A lecturer setting and timed say phrases in .crim reuse the character, poses and captions across slides.Cream은 재생 엔진의 내장 컴포넌트입니다. .crim에 lecturer 설정과 say 대사를 쓰면 슬라이드마다 캐릭터·포즈·말풍선을 다시 만들 필요가 없습니다.

.crim

Edit visually or in text 슬라이드를 텍스트로 편집

Slides, objects, animations and notes are stored in one text file. Select an object and choose View in crim file to see the code that defines it. Edit a value and press Ctrl + Enter (⌘ + Enter on Mac) to apply it to the canvas. The edit can be undone in one step. 슬라이드, 오브젝트, 애니메이션, 메모를 하나의 텍스트 파일에 저장합니다. 오브젝트를 선택하고 crim 파일에서 보기를 누르면 해당 코드가 강조됩니다. 값을 수정한 뒤 Ctrl + Enter(Mac은 ⌘ + Enter)를 누르면 캔버스에 반영됩니다. 수정 내용은 한 번에 되돌릴 수 있습니다.

Choose Edit in crim to open the full file in place of the canvas. If there is a syntax error, the editor highlights the line without applying the edit. crim으로 편집을 선택하면 캔버스 대신 파일 전체를 열어 편집할 수 있습니다. 문법 오류가 있으면 해당 줄을 표시하고, 수정 내용을 적용하지 않습니다.

AI annotateAI 메모

Leave a note where it needs work 고칠 부분에 직접 메모

Use AI annotate to mark an area and describe what to change. On an animated slide, the note also records the current frame. A dot marks it on the timeline, and the note appears faded when you move to another frame. AI 메모를 켜고 수정할 영역을 지정한 뒤, 원하는 변경 내용을 적습니다. 애니메이션이 있는 슬라이드에서는 현재 프레임도 함께 기록합니다. 메모를 남긴 시점은 타임라인에 점으로 표시되며, 다른 프레임으로 이동하면 메모가 흐리게 보입니다.

Notes are editing instructions and are excluded from exported images and videos. The file stores each note with its frame and object names, so AI can identify the scene and objects to edit. 메모는 수정 요청을 위한 것으로, 내보낸 이미지나 동영상에는 포함되지 않습니다. 파일에는 메모와 함께 프레임과 대상 오브젝트 이름이 저장됩니다. 따라서 AI가 어느 장면의 어떤 부분을 고칠지 확인할 수 있습니다.

AI chatAI 채팅

Describe the change.
See it on the slide. 수정을 요청하고,
슬라이드에서 확인

Connect your ChatGPT account using the connection indicator in the top bar, then choose a model and reasoning effort. Crimate uses your existing plan, with no API key required. Keep the chat beside the slide or float it over the canvas. 상단의 연결 상태 버튼에서 ChatGPT 계정을 연결하고, 모델과 추론 강도를 선택합니다. 별도의 API 키 없이 기존 ChatGPT 요금제로 사용할 수 있습니다. 채팅은 슬라이드 옆에 고정하거나 캔버스 위에 띄울 수 있습니다.

Choose English or Korean in Preferences to change the interface language. Slide content and saved conversations stay in their original language. 환경설정에서 화면 언어를 한국어 또는 영어로 바꿀 수 있습니다. 슬라이드 내용과 저장된 대화는 원문을 유지합니다.

  • Describe the edit in chat or refer to a note on a specific frame.채팅에 수정할 내용을 적거나, 특정 프레임에 남긴 메모를 참고하도록 요청합니다.
  • Use @2 to select slide 2 for editing. Attach other slides or decks as references without changing them.@2를 입력하면 2번 슬라이드를 수정 대상으로 지정합니다. 다른 슬라이드나 문서는 수정하지 않고 참고만 하도록 첨부할 수 있습니다.
  • Edits are validated before they are applied. All changes in one reply can be undone together. Save when you want to keep them.수정 내용은 유효성 검사 후 적용합니다. 한 응답에서 적용한 변경은 한 번에 되돌릴 수 있으며, 문서는 직접 저장합니다.
  • View equations and diagram previews in replies. Chat history is saved for each document. You can reopen, rename or delete a conversation.응답에서 수식과 도형 미리보기를 확인할 수 있습니다. 대화는 파일별로 저장되며, 다시 열거나 이름을 바꾸고 삭제할 수 있습니다.

Your instructions and preferences내 지시문과 환경설정

Edit the default AI instructions in Preferences. Ask AI to rearrange menu buttons, change in-app shortcuts or adjust supported settings, with Undo. These requests cannot change the app's source code or grant file access.환경설정에서 AI 기본 지시문을 직접 편집합니다. AI에 메뉴 버튼 배치, 앱 단축키, 허용된 설정 변경을 요청하고 되돌릴 수 있습니다. 이 요청으로 앱 소스를 바꾸거나 파일 권한을 추가할 수는 없습니다.

Use your own references내 자료를 참고한 답변

Choose which folders AI can read in Preferences. It can refer to text, code, PDFs and images, but cannot modify the files. You can revoke access at any time. In the web app, folder access is on the server computer.환경설정에서 AI가 읽을 수 있는 폴더를 지정합니다. AI는 텍스트, 코드, PDF, 이미지를 참고할 수 있지만 원본 파일을 수정할 수는 없습니다. 읽기 권한은 언제든 해제할 수 있습니다. 웹 앱에서는 서버 컴퓨터의 폴더를 읽습니다.

Web search with source links웹 검색과 출처 확인

Enable web search to look up outside sources. The reply includes links to the pages it cites. Once AI accesses local files, it makes no further web searches for that request.웹 검색을 켜면 외부 자료를 찾아 답변에 참고하고, 인용한 페이지를 링크로 표시합니다. 한 요청에서 로컬 파일에 접근한 뒤에는 추가로 웹 검색을 하지 않습니다.

Platforms & availability지원 환경과 배포 현황

macOS, Windows and LinuxmacOS, Windows, Linux에서

Crimate can be packaged as a desktop app for macOS, Windows and Ubuntu/Linux. It is still in private development, with no public downloads yet.macOS, Windows, Ubuntu/Linux용 앱으로 빌드할 수 있습니다. 현재 비공개 개발 중이며, 설치 파일은 아직 공개하지 않았습니다.

  1. .dmg / .zip

    macOS

    Builds for Apple silicon and Intel Macs, with standard macOS open and save dialogs and .crim file associations.Apple silicon과 Intel Mac용으로 빌드합니다. macOS의 파일 열기·저장 창과 .crim 파일 연결을 지원합니다.

  2. .exe

    Windows

    An installer that adds a desktop shortcut and associates .crim files with Crimate. Uses standard Windows open and save dialogs.설치 시 바탕 화면 바로가기를 만들고 .crim 파일을 앱에 연결합니다. Windows의 파일 열기·저장 창을 사용합니다.

  3. .AppImage

    Ubuntu / Linux

    An AppImage build with the same canvas, timeline and AI tools.AppImage 형식으로 빌드하며, 같은 캔버스·타임라인·AI 도구를 제공합니다.

Also in the browser브라우저에서도

Run the editor on your own server and open it in a browser. AI chat and file access run on that server. A public web service is not available yet.개인 서버에서 편집기를 실행한 뒤 브라우저로 접속할 수 있습니다. AI 채팅과 파일 접근은 해당 서버에서 처리합니다. 누구나 접속할 수 있는 공개 웹 서비스는 아직 제공하지 않습니다.
